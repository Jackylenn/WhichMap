# WhichMap

A lightweight Gorilla Tag mod that displays which map each player is currently in directly on the room scoreboard.

## Features
- **Dynamic Updates**: Automatically updates player locations every second as players travel between zones.
- **Full Zone Support**: Supports all base game zones (Forest, City, Canyons, Beach, Mountains, Caves, Clouds, etc.), rotation maps, VIM experiences, and custom maps.
- **Lightweight**: Tiny footprint with zero performance overhead.

## Installation
1. Make sure you have **BepInEx** installed for Gorilla Tag.
2. Download `WhichMap.dll` from the latest release.
3. Drag `WhichMap.dll` into your `Gorilla Tag/BepInEx/plugins/` directory.
